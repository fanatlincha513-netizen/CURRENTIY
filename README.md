# Currency — порт на Minecraft 1.12.2

Исходный мод: **Currency** от Ionaru (Forge 1.7.10, https://github.com/Ionaru/Currency).
Полный перенос на Forge 1.12.2 — код написан заново под новое API.

## Как восстанавливалась логика

У автора не было доступного исходного кода (.java), только скомпилированный jar.
Обычный декомпилятор поставить было нельзя (нет доступа в интернет в среде,
где собирался порт), поэтому:

- 28 предметов и их текстовые подсказки ("0.01 Credits", "1 Credit" и т.д.)
  восстановлены из строковых констант в class-файлах — это надёжно, однозначно.
- Все **69 рецептов обмена номиналов** (какая монета/банкнота/карта на какую
  меняется и в каком количестве) извлечены не на глаз, а через собственный
  дизассемблер байткода JVM и символьный интерпретатор стека, написанные
  специально для этой задачи. Каждый рецепт проверен на соответствие реальным
  инструкциям байткода метода `Currency.load()` оригинального мода.
  Все ингредиенты — ровно по 1 штуке (повторяются в рецепте, если нужно больше),
  количество на выходе иногда 2 или 5 — это тоже видно из байткода напрямую.

## Сборка (Windows)

Нужна **Java 8** и интернет (Gradle сам качает Forge, Minecraft и маппинги).

```
gradlew.bat build
```

Первый запуск — 5-15+ минут. Готовый мод: `build/libs/Currency-1.2.0.jar`.

## Что перенесено

- 28 предметов-номиналов (от Penny=0.01 до IridiumCard=1.000.000.000 Credits).
- Единый класс `ItemMoney` вместо дублирования — подсказка берётся из
  конструктора, а не сравнением unlocalized name, как было в оригинале.
- Конфиг `enableAllRecipes` / `enableAllTooltips` (категория `general`,
  оба по умолчанию `true`) — через `@Config`, с рабочим экраном настроек.
- Вкладка креатива "Currency" с иконкой Penny — как в оригинале.
- Все 69 рецептов обмена (мелкие → крупные и обратно, плюс альтернативные
  комбинации через несколько номиналов) — через `ShapelessOreRecipe`,
  регистрируются только если `enableAllRecipes == true`.
- Регистрация предметов через `RegistryEvent` (обязательно в 1.12.2),
  модели — простые плоские JSON-иконки (`item/generated`), текстуры
  скопированы из оригинального jar и переименованы в нижний регистр.

## Что не переносилось (в оригинале этого не было)

Ничего не пропущено сознательно — у оригинального мода не было ни блоков,
ни TileEntity, ни рендера, ни генерации в мире — только предметы и рецепты,
и всё это перенесено полностью.

## Известные ограничения порта

- Названия рецептов в реестре — технические (`currency:exchange_0` ...
  `currency:exchange_68`), в оригинале своих ID у рецептов не было
  (1.7.10 не требовал регистрировать рецепты по имени).
- Author указан как Ionaru — это порт, а не отдельный мод. Публиковать
  без разрешения автора не стоит; для личного использования — без ограничений.
